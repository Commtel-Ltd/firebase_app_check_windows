# Firebase App Check for Flutter - Standalone Package

A standalone version of Firebase App Check for Flutter, extracted from the FlutterFire monorepo to allow for independent modifications and contributions.

## Installation

Add this to your `pubspec.yaml`:

```yaml
dependencies:
  firebase_app_check:
    git:
      url: https://github.com/yourusername/firebase_app_check_windows.git
```

Or reference a specific branch/tag:

```yaml
dependencies:
  firebase_app_check:
    git:
      url: https://github.com/yourusername/firebase_app_check_windows.git
      ref: main # or specific branch/tag
```

## Usage

This package maintains the same API as the original Firebase App Check package. Please refer to the [Firebase App Check documentation](https://firebase.google.com/docs/app-check) for usage instructions.

## Getting Started

To get started with Firebase App Check for Flutter, please [see the documentation](https://firebase.google.com/docs/app-check/flutter/default-providers).
